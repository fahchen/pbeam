# 2026-11-21 - Shared CI test builds, task [#1665](https://github.com/fahchen/pbeam/issues/1665), pull request [#1666](https://github.com/fahchen/pbeam/pull/1666)

The Elixir test job publishes the compiled fixtures that the Rust tests need. The Rust build job creates one nextest archive with incremental compilation disabled. The Rust test job restores both artifacts. Rust test binaries keep source line tables for failure diagnostics.

These were separate hosted runner sessions. They establish the sizes that CI uploaded. They give no controlled comparison of elapsed time.

## Restore checks

The first run failed because the target directory was already present. The second run reached the nextest path check and failed because the target path left the workspace. A test with a workspace-external target symlink reproduced this failure with pinned nextest. Removing only the link allowed nextest to restore the archive and left the target of the link intact. The restore step invokes nextest directly and keeps its path check enabled.
